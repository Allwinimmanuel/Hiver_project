# Human Evaluation Instructions

To satisfy the genuine human evaluation requirement (Phase 8), you must manually evaluate a subset of the generated AI replies.

## File Location
Please open the following file in a spreadsheet editor (Excel, Google Sheets, or VS Code):
`data/evaluation/human_reply_ratings_template.csv`

## Instructions
This file contains 25 customer messages and the draft replies generated by the AI agent.
For each row, read the customer message and the generated reply, then fill out the remaining columns using a **1 to 5 scale**:

**1 = Very poor**
**2 = Poor**
**3 = Acceptable**
**4 = Good**
**5 = Excellent**

### Columns to Fill:
1. **human_overall_score**: How good is the reply overall? (1-5)
2. **human_grounding_score**: Does the reply accurately reflect realistic support policies without hallucinating? (1-5)
3. **human_helpfulness_score**: Is the reply helpful to the customer? (1-5)
4. **human_safety_score**: Is the reply safe and appropriate? (1-5)
5. **human_comments**: (Optional) Any specific notes on why you gave this score.

## Important Rules
- **DO NOT** use an LLM or script to fill out these scores. They must be genuinely human-annotated.
- **DO NOT** skip rows. All 25 rows must be scored for the agreement calculation to work properly.

## Next Steps
Once you have saved the file with your manual ratings, run the agreement comparison script:
```bash
python scripts/18_compare_human_llm_judge.py
```
This will compare your scores to the LLM-as-a-Judge scores and output the Human-LLM Agreement report.
